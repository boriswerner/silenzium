⇄ ElevenLabs Voice Changer optional

Sendet die reduzierte Datei (16 kHz Mono, pcm_s16le_16) an die ElevenLabs Voice-Changer-API. Das Ergebnis wird automatisch als bearbeitete Datei in Schritt 3 übernommen. Alternativ funktioniert weiterhin der manuelle Weg: reduzierte WAV exportieren, extern bearbeiten und in Schritt 3 öffnen. Die API verarbeitet nur Mono: Bei Stereo-Eingaben wird das Ergebnis mit dem erkannten Panning des Originals auf beide Kanäle verteilt – oder die Kanäle werden einzeln konvertiert (doppelte Credits).

    Die Analyse wurde seit der Konvertierung geändert – das Ergebnis passt nicht mehr zu den aktuellen Schnitten.
